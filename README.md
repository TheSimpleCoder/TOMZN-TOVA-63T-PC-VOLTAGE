# ReleVoltage

ReleVoltage — приложение для Windows, которое отображает текущее напряжение в панели задач. Приложение написано на C# с использованием Windows Forms и целевой платформы .NET Framework 4.8.1.

## Как это работает

- Приложение показывает значение напряжения рядом с областью уведомлений Windows.
- Значение передаётся вспомогательным Python-скриптом `rele.py` через стандартный вывод.
- Для обновления показания скрипт должен выводить строку в формате `VOLTAGE:<значение>`, например `VOLTAGE:230.0`.
- Цвет показания меняется в зависимости от значения напряжения.

Скрипт `rele.py` — обязательная часть проекта. В нём нужно указать необходимые для вашей системы данные и настройки источника напряжения, а также реализовать вывод измеренного значения в описанном формате. Конкретные параметры и библиотеки зависят от используемого оборудования или API.

## Требования

- Windows
- Visual Studio с поддержкой .NET Framework 4.8.1
- Python, доступный по команде `python`
- Файл `rele.py` из проекта в рабочей папке приложения при запуске (рядом с `ReleVoltage.exe`)
- Библиотеки Python, необходимые для работы с выбранным источником данных

## Сборка и запуск

1. Откройте `ReleVoltage.slnx` в Visual Studio.
2. Соберите решение в конфигурации Debug или Release.
3. Заполните в `rele.py` настройки, необходимые для подключения к вашему источнику данных.
4. Установите нужные для `rele.py` библиотеки командой `python -m pip install <имя-библиотеки>` (для нескольких библиотек повторите команду; если в проекте есть `requirements.txt`, используйте `python -m pip install -r requirements.txt`).
5. Убедитесь, что `rele.py` находится рядом с собранным `ReleVoltage.exe`, и запустите приложение. При закрытии приложения запущенный им процесс Python завершается.

При запуске приложение вызывает `python -u rele.py`. Сообщения скрипта в стандартный вывод, начинающиеся с `VOLTAGE:`, используются для обновления показания.
